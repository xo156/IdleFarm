# Idle Farm

Unity 6 기반으로 제작한 방치형(Idle) 농장 게임입니다.

단순한 클릭 게임이 아닌, 데이터 중심 구조와 유지보수를 고려한 설계를 목표로 제작했습니다.

---

## 개발 환경

- Unity 5
- 2022.3.62f3
- C#
- Visual Studio 2022

---

## 주요 기능

### 농장 시스템

- 자동 작물 생산
- 작물 판매
- 오프라인 보상

### 업그레이드 시스템

- 생산량 증가
- 판매 가격 증가
- 업그레이드 레벨에 따른 작물 변경

### 상점

- 소비 아이템 구매
- 펫 구매
- 테마 구매

### 인벤토리

- 보유 아이템 관리
- 펫 장착
- 테마 장착

### 펫 시스템

- 여러 마리 보유
- 한 마리 장착
- 장착 시 능력치 증가

### 테마 시스템

- 여러 개 보유
- 하나 장착
- 농장 배경 변경

### 프레스티지

- 게임 초기화
- 영구 배율 증가

### 저장

- JSON 저장
- 자동 저장
- 자동 불러오기

## 사용 기술

- ScriptableObject 기반 데이터 관리
- JSON Save System
- Event 기반 UI 갱신
- Popup Manager
- Inventory System
- Equipment System
